02CASE STUDY / PROCESS

This project focuses on developing a user-friendly GUI using Tkinter to efficiently check car braking pads. The system integrates a Convolutional Neural Network (CNN) to analyze braking pad images and classify them based on wear and tear. It is specifically designed for RANE car braking pads, but the CNN model can be adapted for other datasets.

Since the dataset cannot be shared, the provided code demonstrates the CNN architecture, allowing users to experiment with different datasets and fine-tune the model.
