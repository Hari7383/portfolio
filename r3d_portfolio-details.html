This project uses an R2+1D video model to detect cashlifting from surveillance footage by learning spatio-temporal patterns. It classifies actions as normal or fraudulent in real time and flags suspicious events for security review.

Developed Fraud Detection Pipeline using R2+1D

  • Built a video-based pipeline leveraging spatio-temporal feature extraction.
  • Preprocessed surveillance footage into frame sequences for model input.
  • Integrated data loaders, normalization, and uniform sampling for reliable training.

Implemented Real-Time Fraud Behavior Detection

  • Deployed inference script to classify live video streams as normal or fraudulent.
  • Applied sliding-window frame analysis to monitor continuous activity.
  • Rendered visual alerts onto video frames to highlight suspicious behavior.

Optimized R2+1D Model for Higher Detection Accuracy

  • Fine-tuned model using class balancing and dropout regularization.
  • Improved accuracy by adjusting window size, stride, and frame sampling strategy.
  • Validated performance using classification metrics and iterative refinement.
